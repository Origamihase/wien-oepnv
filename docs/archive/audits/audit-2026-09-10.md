## Audit Update 14:35

### Affected Component
`src/build_feed.py` (Translation Logic / Domain Glossary)

### Display Issue Description
In the English RSS feed (`docs/feed.en.xml`), the German word "Einstieg" is incorrectly treated as an entity (proper noun) and remains untranslated in phrases like "Einstieg for Vorgartenstraße before Meiereistraße". This results in clumsy phrasing and a partial German/English mix in what should be a fully translated title.

### Proposed Solution
Update the domain glossary (`_apply_domain_glossary` in `src/build_feed.py` or the underlying `dict`) to explicitly map "Einstieg" to "Boarding" or "Entrance", so that it is properly substituted via `XGLO` placeholders rather than being masked as an `XENT` proper noun.

### Affected Component
`scripts/generate_markdown_stats.py`

### Display Issue Description
The generated Markdown statistics page (`docs/statistik.md`) exhibits a UI inconsistency. The section headings use the full word "Minuten" (e.g., `### Verspätungen ⌀ Minuten je Wochentag`), but the corresponding data rows underneath it use the abbreviation "min" (e.g., `1.5 min`). The memory guidelines dictate consistently using the abbreviation 'min' instead of 'Minuten' for delay durations.

### Proposed Solution
Modify `scripts/generate_markdown_stats.py` to replace the word "Minuten" with "min" in the headings for both weekday and hour average delays (change to `### Verspätungen ⌀ min je Wochentag` and `### Verspätungen ⌀ min je Stunde`).

### Affected Component
`src/providers/wl_text.py`

### Display Issue Description
There is a concatenated date string issue appearing in the feeds where titles like "Bauarbeiten ab 14.09.26" are mangled into "Bauarbeiten26". This is caused by the date-stripping regex `_tidy_title_wl` making the 4-digit year optional and stranding 2-digit years, which then erroneously attach to the preceding word. The cache (`cache/wl_9d709a/events.json`) for line `17A` shows exactly this: `"title": "17A: Bauarbeiten26"`.

### Proposed Solution
Fix the regex in `_tidy_title_wl` within `src/providers/wl_text.py` to properly account for and strip 2-digit years without stranding them and merging them into the preceding noun.
