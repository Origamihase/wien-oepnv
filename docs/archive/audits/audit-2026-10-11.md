# Audit Report: 2026-10-11

## 1. UI Consistency: Inconsistent Use of "min" Abbreviation

**Affected Component:** `scripts/generate_markdown_stats.py`, `docs/assets/site.js`

**Display Issue Description:**
In statistics tables and dashboard outputs, the abbreviation "min" is not consistently used. The hardcoded word "Minuten" appears in multiple headings and text blocks within `scripts/generate_markdown_stats.py` (e.g., `### Verspätungen ⌀ Minuten je Stunde`, `Letzte 60 Minuten`). The same inconsistency is present in `docs/assets/site.js` (e.g., `const REFRESH_MS = 5 * 60 * 1000; // 5 Minuten`, `>= 9 Minuten`). This creates visual disharmony across the project's UI.

**Proposed Solution:**
Update all instances of the hardcoded word "Minuten" (and "minute" where applicable) in `scripts/generate_markdown_stats.py` and `docs/assets/site.js` to the standard abbreviation "min".

## 2. Incomplete Title Sanitization: "am" Dates Not Stripped

**Affected Component:** `src/providers/wl_text.py`

**Display Issue Description:**
The feed generation pipeline does not correctly strip dates starting with "am" from feed titles. For example, the disruption titled "18: LCC-Herbstmarathon am 11.10.2026" retains the redundant date string "am 11.10.2026" in the final feed output. This is because the `_AB_DATE_RE` regex only matches dates starting with "ab".

**Proposed Solution:**
Update the regex used for date stripping (e.g., `_AB_DATE_RE` or create a new one) in `src/providers/wl_text.py` to also match and remove dates starting with "am" (e.g., `am DD.MM.[YYYY]`).

## 3. Glued Word Sanitization: Missing Standard German Articles

**Affected Component:** `src/utils/text.py`

**Display Issue Description:**
The `_GLUED_WORD_RE` regex used to insert spaces into awkwardly concatenated words (common in the OGD City of Vienna payload) misses standard German articles like "Der" and "Die". This results in glued words like "DerFußgängerverkehr" remaining unseparated in the feed descriptions.

**Proposed Solution:**
Update the `_GLUED_WORD_RE` regex in `src/utils/text.py` to include standard German articles like "Der", "Die", and "Das" in its list of allowed opening function words.

## 4. Literal Translation of German Transit Verbs

**Affected Component:** `src/build_feed.py`

**Display Issue Description:**
Literal German transit verbs like "Busse halten" and "Züge halten" are being literally translated or not translated correctly into appropriate English idioms. For instance, in the cache, "26E: Busse halten Bessemerstraße 1-3" is a disruption title. Without appropriate mapping, these can result in confusing English translations that omit prepositions or misinterpret contexts.

**Proposed Solution:**
Add mappings for common literal German transit verbs (e.g., "Busse halten" -> "Buses stop at", "Züge halten" -> "Trains stop at") to the translation domain glossary (`_apply_domain_glossary`) in `src/build_feed.py` to ensure they are replaced with `XGLO` placeholders and correctly translated.
