# Audit Log 2026-10-16

## Audit Update 14:40

### Affected Component
Wiener Linien Source Cache & `build_feed.py` Truncation/HTML Strip

### Display Issue Description
1. HTML Block Tags Stripping: In the raw WL cache, descriptions contain HTML block tags like `<h2>` and `<p>`. When converted to plain text for the XML feeds (`docs/feed.xml`, `docs/feed.en.xml`), the tags are stripped without adding whitespace. This results in glued words in the description output.
2. Glued Words in Baustellen Payload: The Baustellen feed descriptions contain concatenated words (e.g., `DieHaltestelle`, `NähereInformationen`). The regex spacing sanitization `_GLUED_WORD_RE` in `src/utils/text.py` fails to catch standard German articles (e.g., "Die", "Der", "Das"), leaving them glued to subsequent nouns.
3. Inconsistent UI Abbreviations: Both `scripts/generate_markdown_stats.py` and `docs/assets/site.js` use the word "Minuten" instead of the strictly mandated abbreviation "min" (e.g., "Verspätungen ⌀ Minuten je Wochentag" instead of "Verspätungen ⌀ min je Wochentag").
4. Truncated Titles: Baustellen feed titles are occasionally awkwardly truncated mid-word with an ellipsis in the cache and feed (e.g., `...bis Schlachthausgas…`).
5. Stranded Years: The WL cache title preprocessing (`_tidy_title_wl`) uses an optional year regex for dates, which leaves isolated 2-digit years stranded in the text when the year is incomplete or separated, combining with the previous word.

### Proposed Solution
*These issues are documented strictly as a diagnostic review. No code fixes are to be applied during this read-only audit.*
1. In `src/build_feed.py`, replace HTML block tags (`<h2>`, `</p>`, etc.) with spaces or newlines before stripping remaining HTML to prevent text collapsing.
2. In `src/utils/text.py`, extend the `_GLUED_WORD_RE` regex to include German articles (`Der`, `Die`, `Das`, `Nähere`) to successfully sanitize the OGD payload.
3. Replace instances of "Minuten" with "min" across markdown statistics templates (`scripts/generate_markdown_stats.py`) and UI strings (`docs/assets/site.js`).
4. Update truncation logic in `src/providers/baustellen.py` to split string appropriately at word boundaries before adding ellipsis.
5. In `src/providers/wl_text.py`, fix `_AB_DATE_RE` to either enforce full matching of stranded years or safely remove partial date strings to prevent text artifacts like `Bauarbeiten26`.
