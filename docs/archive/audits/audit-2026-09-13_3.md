# Diagnostic Audit: Title Redundancy

**Date:** 2026-09-13
**Affected Component:** `src/providers/wl_text.py` (Title Sanitization / `_tidy_title_wl` or Feed Builder)
**Display Issue Description:**
In the RSS feed, the title for a Wiener Linien event is displayed as `44: Veranstaltung Züge halten Rosensteingasse bei Linie 9 Richtung Westbahnhof`. The phrase `Züge halten Rosensteingasse bei Linie 9 Richtung Westbahnhof` is already present in the description and is unnecessarily repeated in the title. A concise title like `44: Veranstaltung` would be sufficient and more readable on information displays, preventing redundancy and saving space.

**Proposed Solution:**
Update the title sanitization logic (e.g., in `_tidy_title_wl` within `src/providers/wl_text.py` or the item builder) to truncate or filter out descriptions from the title if they merely repeat the body of the event. A regex or string matching approach could be used to remove the redundant text if the title starts with a known topic token like "Veranstaltung" and the rest of the string matches the description text.
