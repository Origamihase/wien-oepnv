# Audit Report 2026-10-04

## Audit Update 14:02

### Affected Component
`src/utils/text.py` (`_GLUED_WORD_RE`) and Baustellen feed data parsing.

### Display Issue Description
The regex spacing sanitization `_GLUED_WORD_RE` inserts spaces based on a strict list of allowed opening function words but misses standard German articles like `Der` and `Die`. This leaves compound words and sentences clumsily concatenated in the source cache payloads, such as "DieArbeiten" and "Derlinke" in the City of Vienna OGD data.

### Proposed Solution
Extend `_GLUED_WORD_RE` in `src/utils/text.py` to also match `Der`, `Die`, and `Das` as valid opening words to properly split these occurrences.

---

### Affected Component
`src/build_feed.py` (`_GLOSSARY_BASE`) and English feed translation.

### Display Issue Description
Literal German transit verbs like "Busse halten" and "Züge halten" are mapped to literal English equivalents ("buses stop", "trains stop") in `_GLOSSARY_BASE`. This leads to clumsy and grammatically awkward translations in `docs/feed.en.xml`, such as "Trains stop for lines 6 and 18" (from "Züge halten bei Linien 6 und 18") and "Buses stop Salvatorianerplatz".

### Proposed Solution
Update `_GLOSSARY_BASE` in `src/build_feed.py` to map these terms to appropriate English idioms, such as "buses stop at" and "trains stop at", to ensure proper preposition usage in the final output.

---

### Affected Component
`scripts/generate_markdown_stats.py` and UI Dashboard Headers.

### Display Issue Description
The script `generate_markdown_stats.py` uses the full word "Minuten" in header titles, such as "### Verspätungen ⌀ Minuten je Stunde". This violates the project-wide UI consistency guideline that mandates the use of the abbreviation "min" for delay durations in statistics tables and dashboard outputs.

### Proposed Solution
Modify `scripts/generate_markdown_stats.py` to replace the word "Minuten" with "min" in the affected markdown headers to maintain visual harmony and consistency across the project outputs.
