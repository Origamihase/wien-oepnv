## Audit Update 14:30

**Affected Component:** `src/build_feed.py` (Feed Generation XML Pipeline)

**Display Issue Description:** The feed output (`docs/feed.xml`) contains an XML tag leaking into the text as an unescaped entity format. Specifically, the `<description>` element of the "42/9: Falschparker" entry contains `Umleitung bis Gersthof &amp;lt; über Linien 42 und 9!`. This happens because `<` is manually mapped to `&lt;` before being passed to `ElementTree`, which then escapes the `&`, resulting in the double-escaped `&amp;lt;`.

**Proposed Solution:** Adjust the description escaping mechanism. Ensure that `<description>` element content does not get double-escaped, by either letting ElementTree handle all the escaping (including `<`), or by bypassing ElementTree's escaping for strings that are already pre-escaped.
