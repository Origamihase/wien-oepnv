# Audit Report 2026-10-05

## Audit Update 14:19

### Affected Component
Feed Generation Pipeline (`src/build_feed.py` HTML to Text processing)

### Display Issue Description
In the generated feeds (`docs/feed.xml`, `docs/feed.en.xml`), the disruption description for the U6 (Neue Donau) exhibits word gluing. The raw payload contained `<h2>Bahnsteigsanierung</h2> <p>Wegen...`, and the resulting description starts with `Bahnsteigsanierung Wegen Sanierung...` without proper punctuation or structural separation, leading to the English translation: `Refurbishing the platform Due to the renovation...` where the heading and body collide.

### Proposed Solution
Enhance the HTML stripping logic in `src/build_feed.py` to insert structural spacing or line breaks when converting block-level tags like `<h2>` and `<p>` to plain text, ensuring consecutive sentences don't glue together.

---

### Affected Component
Feed Generation Translation (`src/build_feed.py` domain glossary)

### Display Issue Description
The English translation for the transit idiom "Züge halten" (e.g., in line O and lines 6/18 disruptions) is excessively literal: "Trains stop at the stop of line O" or "Trains stop at the stops of lines 6 and 18". This misses the contextual nuance of a transit substitution or temporary arrangement.

### Proposed Solution
Update the domain glossary (`_apply_domain_glossary`) or translation substitutions in `src/build_feed.py` to map these German transit verbs to more appropriate English idioms.

---

### Affected Component
Source Data Payload (Wiener Linien API)

### Display Issue Description
The raw data payload for the Line D disruption contains a spelling error in the station name: "Quatier Belvedere" instead of "Quartier Belvedere", which leaks directly into the generated English feed: "diversion to Quatier Belvedere via lines 2, 1 and O."

### Proposed Solution
Since this is an upstream data error from the Wiener Linien API, a downstream substitution (e.g. adding a fix to the sanitization logic in `src/providers/wl_text.py` or the translation glossary) could be implemented to correct the specific typo "Quatier Belvedere" before it is published.
