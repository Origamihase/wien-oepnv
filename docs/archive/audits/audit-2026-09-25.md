### A.1 — ÖBB-Titel mit Update-Präfix (Rang 2, DE-Feed sichtbar)

| | |
| --- | --- |
| **Betroffene Komponente** | `src/providers/oebb.py` (`_clean_title_keep_places`), `src/build_feed.py` (`_post_filter_oebb`) |
| **Problembeschreibung** | Platz 3 des deutschen Feeds lautet „Update 4 (25.09.2026 09:59) Verkehrseinschränkung: St.Pölten". Das Präfix belegt auf dem Display rund 30 Zeichen ohne Information für den Leser, und „St.Pölten" fehlt das Leerzeichen. Ursache: Die Präfix-Schleife in `_clean_title_keep_places` trennt nur an einem Doppelpunkt, dem keine Ziffer folgt (Schutz für Uhrzeiten); der erste Doppelpunkt steht in „09:59", der Titel bleibt daher unverändert. Ohne das Präfix macht dieselbe Funktion aus „Verkehrseinschränkung: St.Pölten" korrekt „St. Pölten Hauptbahnhof". Seit 01.08. erschienen vier solche Titel im Feed, je zwei bis drei Zyklen. |
| **Konkreter Lösungsvorschlag** | Das Präfix „Update N (TT.MM.JJJJ hh:mm)" vor der Präfix-Schleife entfernen, im Provider und beim Lesen des Caches (`_post_filter_oebb`), damit der gecachte Titel ohne Cache-Refresh repariert wird. Die GUID bleibt am Rohtitel. **Vorsicht:** Drei der vier Titel waren Entwarnungen („Update 1 (…) Aufhebung Verkehrseinschränkung: Wien Handelskai"). Ohne Präfix würde die Schleife „Aufhebung Verkehrseinschränkung:" als Kategorie verwerfen und nur „Wien Handelskai" stehen lassen — eine Entwarnung sähe dann aus wie eine laufende Störung. Ein Präfix, das mit „Aufhebung" beginnt, darf deshalb nicht entfernt werden. |

### A.3 — „bis voraussichtlich 11:00 Uhr" wird „to expected 11:00" (Rang 3, EN)

| | |
| --- | --- |
| **Betroffene Komponente** | `src/build_feed.py`, `_GLOSSARY_BASE` („voraussichtlich" → „expected") |
| **Problembeschreibung** | Heute im EN-Feed: „Due to a switch fault, trains to expected 11:00 are only limited in St.Pölten." Der Glossar-Eintrag ersetzt „voraussichtlich" als Einzelwort; das Modell übersetzt das davorstehende „bis" dann als „to". Im Cache: 64 Werte mit „to/until expected", 50 mit „expected hh:mm". |
| **Konkreter Lösungsvorschlag** | Phrasen-Eintrag vor dem Einzelwort: „bis voraussichtlich" → „until approx." bzw. „expected until" (längster Treffer gewinnt), Epochen-Bump oder gezielter Self-Heal für die betroffenen Werte. |
