# Audit Update 2026-09-18

## Affected Component
`docs/feed.xml` / `docs/feed.en.xml` (Translation Pipeline & Text Presentation)

## Display Issue Description
1. **Missing Redirecting Station in Translation**: In the English feed for "12/2: Veranstaltung", the phrase "Die Züge werden weiter zum Karlsplatz umgeleitet" is translated as "Trains are redirected to the Karlsplatz." The article "the" is awkward and should be removed.
2. **Grammar Mismatch**: For the switch fault on Tullnerfeld, the English feed states: "Due to an switch fault". "switch" begins with a consonant sound, so it should be "a switch fault".
3. **Awkward Phrasing**: For the "12A: Verunreinigung" event, the title translates as "12A: Impurity", but the description translates as "Reason: contamination." There is a mismatch.
4. **HTML in Description**: In the DE cache for "72A: Kraftwerk Simmering", the description contains raw HTML (`<p>`, `<span>`, `<strong>`, etc.). In the DE feed, these are seemingly stripped or escaped, but the text runs together awkwardly without spacing, such as "Haltestellenverlegung der Linie 72A in Richtung Hasenleitengasse Haltestelle: Kraftwerk Simmering Von: 1. Haidequerstraße 2 Nach: 1. Haidequerstraße 510 Dauer: Ab …"
5. **Bold text leak**: In the OEBB cache for Tullnerfeld, there's `<b>waren</b>` and `<br>`. These get stripped but maybe we lose formatting or space. In the feed: "Wegen einer Weichenstörung waren zwischen Tullnerfeld Bahnhof und Wien Meidling Bahnhof (U) bis 15:43 Uhr nur eingeschränkt Fahrten möglich."
6. **Formatting Inconsistencies**: There is inconsistent abbreviation of "Minuten" to "min" across statistics tables in `docs/statistik.md` and `README.md` (e.g., "Verspätungen ⌀ Minuten je Wochentag"). The frontend string definitions in `docs/assets/site.js` use the labels "≥" but logic strictly checks `>`.

## Proposed Solution
- **Translation / Glossary fixes**: Update `src/build_feed.py`'s `_GLOSSARY_BASE` or post-translation cleanup to handle "switch fault" starting with a consonant (e.g. check if the model inserts "an " and correct it, or change the phonetic starting sound mapping if applicable). Add "Verunreinigung" to the glossary consistently as "contamination".
- **HTML stripping**: Update HTML-stripping logic in the feed builder or WL provider (e.g., `src/providers/wl_linien.py` or similar) to replace block-level tags like `<p>` and `<br>` with spaces or newlines instead of completely omitting them, which runs words together.
- **Frontend / Stat Formatting**: Update labels in `docs/assets/site.js` to align with the actual condition (`>`). Standardize the abbreviation "min" in `scripts/generate_markdown_stats.py` instead of using "Minuten".
